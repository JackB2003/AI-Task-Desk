The Work on it button hands a task to an AI agent. AI Task Desk uses Claude Code for that.

Demo: the agent here is simulated, so these checks are pretend. On your own copy they are real.

    Subscription or API key? Can I use another AI?

    Your Claude subscription (Pro or Max): the default. Runs use your plan's allowance. Log in once by running claude in a terminal.

    Your own Anthropic API key: billed per use by Anthropic. Set it up with npm run setup, or put AGENT_AUTH=api and ANTHROPIC_API_KEY=... in the .env file, then restart.

    Other AIs (ChatGPT, Gemini, local models) are not supported yet. Only Claude works today.

    Your key or login never goes into this page. It stays on your machine.
